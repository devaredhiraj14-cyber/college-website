SSBT's Arts, Commerce & Science College — static website project

FILES
- index.html: Home page with hero, introduction, Why Choose Us, courses, campus life, faculty preview, notices, academic calendar, gallery and events.
- contact.html: Contact page and demo form.
- placement.html: Existing placement page included from the provided project. Verify all content before official use.
- css/style.css: Shared styles and responsive layouts.
- js/script.js: Mobile navigation, year, search and contact-form demo behavior.

HOW TO PREVIEW
Open index.html in a browser. Keep the css and js folders alongside the HTML files.

BEFORE OFFICIAL LAUNCH
1. Replace illustrative online images with approved actual college photographs and official logo.
2. Verify programme names, facilities, address, phone/email, faculty details and all official links.
3. Replace calendar placeholders with dates approved by the college. No dates have been invented.
4. Check placement.html carefully: do not publish unverified statistics/claims.
5. Contact form is a front-end demo only; it does NOT send or store messages until connected to an approved form service/backend.
6. Add official social media links only after verifying the college accounts.

GitHub Pages can host this static project. Upload the files and folders preserving this structure.
